# PictoRescate

App web para comunicarse con pictogramas entre bomberos o rescatistas y pacientes con dificultades para comunicarse (autismo, sordera, otras).

Proyecto para el Departamento de Psicología de la Emergencia de Bomberos Voluntarios de Bialet Massé (coordinadora: Psic. Mayra Salomón).

## Funciones
- **Pregunto yo:** el rescatista escribe o dicta una pregunta y la app muestra los pictogramas de respuesta.
- **Habla el paciente:** tablero para que el paciente diga lo que necesita; el rescatista responde con un toque.
- **Conversación:** registro con hora de todo el intercambio, con opción de copiar el texto para el parte.
- Modo claro y oscuro, instalable en el celular (PWA) y funciona sin internet.

## Publicación
Se publica con GitHub Pages desde la rama `main`. Al subir cambios, aumentar `VERSION` en `sw.js` para que los celulares descarguen la versión nueva.
